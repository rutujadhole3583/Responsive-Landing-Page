# PRODIGY_WD_01

## Responsive Landing Page

This project is a responsive landing page developed using HTML, CSS, and JavaScript.

### Features
- Fixed navigation menu
- Interactive hover effects
- Navigation bar changes style on scroll
- Responsive design
- Smooth user experience

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Project Objective
Create an interactive navigation menu that changes color or style when scrolled or when hovering over a menu item. The navigation menu remains fixed and visible on all pages.
